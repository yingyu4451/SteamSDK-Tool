这一版只动了一件事，但影响所有用更新功能的人。

## 更新检查不再依赖 GitHub API

匿名调用 `api.github.com` 有 **60 次/小时/IP** 的额度。同一个办公室或学校出口 IP 下几十个人一起用，额度很快打满，更新检查就直接失效。

现在改成读网页端点，没有额度限制，请求数还更少（查一次 2 个请求，原来 4 个）。

## 顺带修掉一个更严重的

改完才发现：**原来的 HTTP 请求走的是 `node:https`，它不认系统代理。**

在挂了代理的机器上（访问 GitHub 的常见配置），同一个地址：

| 客户端 | 结果 |
|---|---|
| 浏览器 / Electron 自己 | 302，秒回 |
| `node:https` | 连续 5 次全部 20 秒超时 |

也就是说，就算额度没问题，**装了代理的人本来就查不到更新**。现在传输层走 Electron 自己的网络栈，系统代理和 PAC 脚本都认。

## 实测

| 场景 | 结果 |
|---|---|
| 已是最新 | 669 ms · 判定正确 |
| 有新版 | **235 ms** · 版本号 / 体积 / 发布日期 / 更新说明全部拿到 |
| 下载安装包 | 字节数一字不差，进度 0→100% 正常 |
