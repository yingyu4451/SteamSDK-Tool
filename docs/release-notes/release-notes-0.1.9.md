这一版都是「用起来顺手」的修补。

## 安装向导

- 左侧换成应用同一套配色的竖图，加了欢迎页
- **默认安装目录改成 `D:\SteamSDK Tool`**（D 盘存在时；已经装过的升级不会被挪位置）
- 目录页手填盘符根时自动补目录名 —— 以前填 `D:\` 那个「安装」按钮会直接变灰点不动

## 增量更新

更新不再每次重下 106 MB，只下改动的块。

## 构建输出

高度固定，底边跟左边「分支 / SetLive」齐平。日志再长也只在框里滚，不会把整页撑高。

## 任务栏图标

修掉「图标隔几天又变回 Electron 原子球」：开发版和打包版以前共用同一个 AppUserModelId，我每次跑开发版都会让 Windows 把那个身份跟 `electron.exe` 的图标绑一次。
现在两套身份分开了。
