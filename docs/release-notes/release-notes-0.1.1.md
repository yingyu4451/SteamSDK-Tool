上一个版本之后攒了一轮界面和稳定性改动。功能没变，但用起来应该顺不少。

## 界面

- **换成 Steam 客户端配色**：深蓝底 `#171a21`、链接蓝 `#66c0f4`，「正式上传」是 Steam 那种绿色 Play 按钮。按钮和卡片底色拉开了明显对比 —— 之前两者几乎一样，看不出哪个能点
- **重绘 logo**：等距立方体 + 从箱子里升起的上传箭头。窗口左上角、任务栏、安装程序现在都是同一个
- **字体**：中文 MiSans、西文和数字 JetBrains Mono
- **图标统一走 [Lucide](https://lucide.dev)**：33 个手写内联 SVG 全换掉。侧栏状态灯三种状态改成同一个圆点、只换颜色（之前绿的是点、黄的是地球、红的是三角，同一个语义三种形状）
- **首次运行引导**：三步 —— SDK 在哪 / Steam 账号 / 完事。老用户直接点「跳过教程」
- 设置分成左右两栏；工具条面板改成浮层，不再把下面的内容顶下去
- 切 App 加了过渡；构建输出的底边和分支面板齐平

## 功能

- **本地内容服务器**：不用先上传就能在 Steam 客户端里试玩。原来走 SDK 自带的 `mongoose-3.1.exe`，实测在有些机器上进程能起来但**根本不监听端口**；现在改用 Node 自带的 http，启动后真发一次 HTTP 请求确认在服务。面板上加了「一键配好并送进去」，五步一次跑完
- **待处理清单常驻**：每一条都能单独「本次忽略」或「永久忽略」，忽略掉的收起来还能恢复
- **App 名字可以带空格和括号**了（之前白名单写错，把它挡掉了）
- **新建 Depot 走侧边栏**，字段照着 Steamworks 后台来：名称 / DepotID / 操作系统 / 架构。选了 macOS 就不会再列 32 位这种不存在的选项
- **「检查配置」「检查文件」**：原来叫「自检」「预检」，看不出区别
- **应用内使用手册**：侧栏第四项，离线可用，能按关键词搜
- **新手教程和设置里都能直接去下 Steamworks SDK**

## 安全

- 去掉源码和文档里硬编码的 Steam 账号名

## 安装

下载下面的 `SteamSDK Tool-0.1.1-setup.exe`。

首次打开会有三步引导，或者手动到「设置」里填两样：

1. **SDK 路径** —— 你的 SteamSDK 目录（比如 `D:\SteamSDK`）
2. **Steam 账号密码** —— 跑 steamcmd 的账号（不是邮箱）。密码用 Windows DPAPI 加密后存在本机，不写进命令行参数
