## 拖 .zip 导入不了

上一版为了让解压时能显示进度条，把解压改成了异步的。但调用它的那一处还是按同步写的 —— 拿到的是个 Promise，`r.ok` 永远是 `undefined`，于是**每次都走失败分支**。

所以表现很怪：拖文件夹好好的，拖 `.zip` 一律失败，跟包大小、格式都没关系。

修了之后：

- 拖 `.zip` 能正常识别并导入
- 分析阶段已经把包解开了，导入时**不再重新解一遍** —— 616 MB 的包导入是 **0 秒**（以前要再等十几秒）
- 解出来的内容会挪到 `D:\SteamBuilds\<包名>` 这个稳定位置再绑成内容目录，不会指向临时目录

实测拿 `Loopstructor 2_ Skyspine_1.425_Steam.zip`（616.6 MB / 372 个文件 / 解压 1.87 GB）：分析 11.4 秒、导入 0 秒、内容目录正确、文件数对得上。
